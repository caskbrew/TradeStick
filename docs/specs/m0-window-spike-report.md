# M0 Window Spike — отчёт

Дата: 2026-10-14. macOS 26.7, Xcode 27 / Swift 6.4. Спайк (одноразовый код, `Sources/WindowSpike`) проверялся вручную заказчиком; результаты приведены по его сообщениям. Пункты, которые не проверялись, помечены явно и **не считаются пройденными**.

## Что наблюдалось

| Наблюдение | Результат |
|---|---|
| Приложение стартует как агент (пункт `TS` в строке меню, без Dock-значка), `New Sticker` создаёт независимые окна, их можно перетаскивать за фон | PASS (M0-1, M0-2) |
| Закреплённый стикер (floating + `canJoinAllSpaces` + `fullScreenAuxiliary`) виден на всех Spaces и над полноэкранным терминалом | PASS (M0-4, M0-5) в конфигурации «Pin включён» |
| `Stationary` | Работает (заказчик подтвердил), но в итоговую модель не вошёл |
| Pin выключен, но `canJoinAllSpaces` остался | Окно всё равно переходило на другие Spaces: Pin менял только уровень окна |
| Non-activating панель: другие окна перекрывают стикер, даже когда в нём курсор | Ожидаемо для non-activating панели; исправление требует активировать приложение, то есть отбирать фокус (отказались от печати без кражи фокуса, M0-3) |
| Pin выключен на полноэкранном Space | Окно остаётся на этом Space. У окна нет «домашнего» Space, программно вернуть его в AppKit нельзя |
| Эксперимент: снять `fullScreenAuxiliary` и `canJoinAllSpaces` + `orderOut`/`orderFront` | Не помогло: окно мигнуло и осталось на том же Space |
| Режим `.accessory` | Клик по стикеру не показывает меню приложения слева вверху; Cmd+W без главного меню не работает |
| Эксперимент: `.regular` + главное меню (Cmd+W, Cmd+Q) при открытых стикерах | Значок в Dock; заказчик отказался от него, откат |

## Не проверено (переносится на M4, проверять на реальном окне)

M0-6 / M0-7 Mission Control, M0-9 плавность раскрытия вниз, M0-10 раскрытие у нижнего края экрана, M0-11 второй монитор и смена разрешения, M0-12 sleep/wake, M0-13 восстановление позиции из frame autosave. Поведение окна, созданного из полноэкранного Space, в итоговой конфигурации «заметка» тоже не описано.

## Решение заказчика

Окна «как заметки»: без Pin, без Stationary, одно рабочее пространство на окно. Окончательная конфигурация спайка (коммит `16cfdcf` + откат `666a81c`):

- Класс: `NSPanel`, `styleMask = [.borderless]`, `canBecomeKey = true`, `isMovableByWindowBackground = true`.
- `level = .normal`, `collectionBehavior = []`, `hidesOnDeactivate = false`.
- Не non-activating: клик и ввод активируют приложение (`NSApp.activate()` + `makeKeyAndOrderFront`).
- Политика активации `.accessory`, без Dock-значка и без главного меню; Cmd+W не поддерживается.
- Раскрытие: `setFrame(animate: true)`, верхний край фиксируется (`origin.y += oldHeight - newHeight`).

## Решения для M4

- Закрытие и скрытие стикера: `⋯ → Hide Window` и пункт меню в строке меню.
- Раскрытие у нижнего края экрана: сдвигать окно вверх на величину переполнения (FR-TX-8), проверить на реальном окне.
- Восстановление позиции: проверять сохранённый frame по `NSScreen.screens`, если монитор исчез.
- Код спайка одноразовый: не импортировать, переносить только перечисленные настройки.
